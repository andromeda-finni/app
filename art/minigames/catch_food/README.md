# Исходники графики «Лови корм»

34 исходных PNG, созданных встроенным ImageGen по утверждённому концепту:
24 изображения кота (три расцветки × восемь поз/состояний) и 10 общих элементов.
Полосатый комплект сохранён; добавлены рыжий и белый с общим красным узорным ошейником и золотым медальоном.

[Каталог всех котов](coats.html) сравнивает каждую позу в трёх расцветках и содержит ссылки на PNG и промпты.
Он показывает готовые WebP из приложения, поэтому доступен после экспорта.

`manifest.json` содержит размеры, назначение, референсы, промпты и исходные ориентиры размещения.
Полные промпты находятся в `prompts/`, копии использованных референсов — в `references/`.
`preview.html` открывает каталог общих элементов без сети. `validation.json` подтверждает размеры,
прозрачность и отсутствие обрезанных краёв для 34 файлов. Повторная проверка на Windows:
`./art/minigames/catch_food/tools/inspect-assets.ps1` из корня репозитория (PowerShell 7).

К золотой рыбке добавлен испорченный круглый корм с красным крестиком — его нужно пропускать.
Референс материала для него — `food_fish.png`, промпт — `prompts/food_spoiled.txt`.
Фон и первоначальная карточка входа непрозрачные; остальные 32 файла содержат прозрачность.
Для новых расцветок изменялись только пигменты шерсти в оригинальных позах; их геометрия,
миски, выражения, коллизии, красный ошейник и медальон сохранены.

| ID питомца | Расцветка | Исходники | WebP |
|---|---|---|---|
| `FUR_GRAY` | Полосатый | `cat_*.png` | Корень `assets/minigames/catch_food/` |
| `FUR_ORANGE` | Рыжий | `variants/orange/cat_*.png` | `assets/minigames/catch_food/orange/` |
| `FUR_WHITE` | Белый | `variants/white/cat_*.png` | `assets/minigames/catch_food/white/` |

Синий и зелёный ошейники сознательно не размножают набор по согласованному с пользователем
упрощению. Варианты ошейника в других экранах игры не меняются.

В приложении используются уменьшенные WebP, а не эти исходные PNG. Для повторного экспорта:

```sh
python tools/export_catch_food_assets.py
```

Можно экспортировать только одну расцветку: `python tools/export_catch_food_assets.py --coat orange`
(также `white` или `striped`). Промпты новых расцветок: `prompts/orange/` и `prompts/white/`;
референсы цвета взяты из существующих `assets/Cat/Red_collar/base/red.webp` и `white.webp`.

Требуется Pillow. Экспорт сохраняет alpha и пропорции; результат попадает в
`assets/minigames/catch_food/`. UI, кнопки и шкалы реализованы средствами Flutter.
Измеренные точки мисок и лап откалиброваны в `lib/minigames/catch_food/catch_food_board.dart`.
Правила и проверка игры: `docs/minigames/catch-food/README.md`.
