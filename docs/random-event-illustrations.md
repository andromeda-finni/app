# Иллюстрации случайных событий

Шесть иллюстраций заменяют серые заглушки в `PetEventDialog`. Внешность питомца игрок выбирает сам, поэтому котёнка, его силуэта и ошейника на изображениях нет. Единственный персонаж набора — Бобр из события `BEAVER_DAM`.

| Событие | Иллюстрация | Файл |
| --- | --- | --- |
| `POOR_PAW` | Подорожник, бинт, колючка и бабочка на лесном пне | `assets/events/poor_paw.webp` |
| `SICK` | Липовый чай, мёд и тёплый шарф у дождливого окна | `assets/events/sick.webp` |
| `HUNGRY` | Горячая похлёбка, ложка и пустая корзинка | `assets/events/hungry.webp` |
| `COLD_NIGHT` | Остывшая печка и пустая корзина для дров | `assets/events/cold_night.webp` |
| `ROOF_LEAK` | Капли из повреждённой крыши и ведёрко | `assets/events/roof_leak.webp` |
| `BEAVER_DAM` | Бобр, отремонтированный мостик и монетки на общий сбор | `assets/events/beaver_dam.webp` |

Изображения созданы встроенным `image_gen` по существующим фонам домика и пекарни. Полный набор промптов сохранён в `random-event-art-prompts.json`: для каждого изображения использованы общий `base` и соответствующий `scenes[].scene`.

Формат для приложения: WebP, 960 × 640, качество 84, соотношение сторон 3:2. Иллюстрация показывается целиком, со скруглением из темы приложения; экранный диктор получает название события с выбранным именем питомца. Файлы перечислены в `pubspec.yaml`, поэтому доступны без сети. Суммы, тексты, серверная генерация событий и обработка оплаты остаются прежними.

Картинка голода показывает нужную похлёбку как предмет помощи; печка и крыша показывают проблему до оплаты. Это художественная интерпретация существующих описаний, без новых игровых правил.
