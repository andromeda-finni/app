# Грошик — Интерактивный Wireflow

Интерактивный вайрфрейм и карта пользовательских сценариев (wireflow) финансово-образовательного приложения «Грошик».

Проект поддерживает две версии с возможностью мгновенного переключения между ними и раздельным сохранением прогресса:
- **v0.3 (актуальная)** — новая итерация с изменениями команды (онбординг, сложность, PIN взрослого, шкалы персонажа, единая карта с Хитрым Лисом, страхование у стола подорожника).
- **v0.2 (исходная)** — базовая согласованная версия (разделение Леса и Тридевятого царства, витрина артефактов, классический домик).

---

## Способы переключения версий

1. **В интерфейсе**: в верхней шапке приложения добавлен переключатель `[ v0.2 ] [ v0.3 (новая) ]`, доступный на каждом экране.
2. **Через URL-параметры**:
   - `?v=0.2` — автоматически открывает версию 0.2 (например, `index.html?v=0.2` или `wireflow.html?v=0.2`).
   - `?v=0.3` — открывает версию 0.3.
3. **Прямые файлы и ссылки**:
   - **Главная страница (v0.3)**: `index.html` (или `outputs/wireflow.html`, `outputs/wireflow-v03.html`)
   - **Версия 0.2**: `index-v02.html` (или `outputs/wireflow-v02.html`)
4. **Маршруты Vercel**:
   - `/` и `/wireflow` → версия 0.3
   - `/v02`, `/v2`, `/wireflow-v02` → версия 0.2
   - `/v03`, `/v3`, `/wireflow-v03` → версия 0.3

---

## Сохранение прогресса и совместимость

- Обе версии работают полностью локально в браузере без внешних зависимостей и сети.
- Данные v0.2 и v0.3 изолированы:
  - Версия 0.2 использует ключ `groshik-wireflow-v01`.
  - Версия 0.3 использует ключ `groshik-wireflow-v03` с автоматической миграцией существующего баланса и коллекций при первом запуске.
- Прогресс в одной версии не перезаписывает и не повреждает данные другой.
- Кнопка «Начать заново» сбрасывает состояние только для активной версии.

## Сравнение версий v0.2 и v0.3

| Механика | Версия 0.2 | Версия 0.3 (новая) |
|---|---|---|
| **Вход и онбординг** | Создание питомца сразу после знакомства | Знакомство → выбор сложности → создание питомца → 3 шага онбординга |
| **Сложность** | Единая сложность с адаптацией сумм внутри квеста | Низкая / средняя / высокая (влияет на награды и условия) |
| **Главный экран (Домик)** | Баланс, копилка, шкалы сытости/радости, задания | Упрощён: кошелёк, питомец, цель; показатели вынесены |
| **Экран персонажа** | Состояние отображалось в блоке метрик | Отдельный экран (03.1) с полосами сытости, радости и здоровья |
| **Навигация** | Переход через домик и карту леса | Нижний таббар: Дом / Карта / Магазин / Копилка |
| **Карта заданий** | Карта леса (3 квеста) + Тридевятое царство (обзор) | Единая карта заданий с 5 персонажами, доступная сразу |
| **Персонаж темы 5** | Хитрый Купец | Хитрый Лис (возвращён по решению команды) |
| **Магазин и страховка** | Ярмарка с 3 товарами | Единый магазин (еда, игрушки, артефакты) + Стол подорожника (страховка) |
| **Взрослый раздел** | Прямой вход без пароля | PIN-код взрослого (хэш с солью), шаблоны домашних дел, лимит наград ≤50 |
| **Настройки** | Отсутствовали | Экран настроек: сложность, звук, музыка, крупный текст, повтор онбординга |

Полный список изменений зафиксирован в документе [outputs/wireflow-v03-changes.md](outputs/wireflow-v03-changes.md).

## Сборка и тестирование

Проект не требует внешних сборщиков; сборка выполняется средствами Node.js:

```bash
# Пересборка всех файлов (v0.2, v0.3, outputs, root):
node work/v03-build.cjs

# Запуск тестов версии 0.3 (157 проверок):
node work/v03-tests.cjs

# Запуск тестов версии 0.2 (90 проверок):
node work/tests-v02.cjs
```
