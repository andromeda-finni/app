Как смотреть

В центре — приложение. Здесь и справа — пояснения для команды. Переходы сохраняют условия игры.

Версия 0.3 (новая): добавлены выбор сложности, онбординг, экран персонажа со шкалами, единая карта заданий с Хитрым Лисом, стол подорожника и кабинет взрослого с PIN. Чтобы сравнить с исходной версией, нажмите v0.2 в переключателе вверху.

Чтобы пройти новый вход, нажмите «Начать заново»: это удалит только локальный демонстрационный профиль.
