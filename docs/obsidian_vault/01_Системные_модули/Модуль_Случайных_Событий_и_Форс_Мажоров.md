# Модуль Случайных Событий и Форс-Мажоров

## Описание
Симулирует непредвиденные жизненные обстоятельства (поломка, легкая простуда лапки, необходимость купить целебный подорожник). Обучает ребенка важности наличия резервного фонда (подушки безопасности).

## Механика / Бизнес-логика
*(Строго по коду `backend/src/modules/petEvents/routes.ts`, `backend/src/modules/economy/rules.ts`)*
- **Генерация событий:**
  - Текущий клиент получает единственную атомарную попытку события при `POST /periods`; `POST /pet-events/roll` оставлен только как идемпотентный совместимый маршрут для старых клиентов.
  - События начинают генерироваться со **2-го игрового дня** (`firstEventDay = 2`).
  - Вероятность срабатывания при входе в день: **70%** (`eventProbability = 0.7`), если нет другого незакрытого события.
  - Стоимость устранения форс-мажора (`amount_due`): **от 2 до 20 монет**.
- **Влияние на питомца:**
  - Активное неоплаченное событие снижает уровень здоровья питомца на **45 пунктов** (`PET_EVENT_HEALTH_DROP = 45`, здоровье падает до 55%).
  - Оплата события (`POST /pet-events/:occurrenceId/resolve`):
    - Списывает сумму `amount_due` из основного кошелька (деньги списываются в том числе из обязательного резерва, так как медицина — приоритет).
    - Здоровье питомца мгновенно восстанавливается до **100%** (`PET_HEALTH_FULL = 100`).
    - Событие переходит в статус `RESOLVED`.
- **Педагогический принцип:**
  - Ошибки и непредвиденные траты обратимы. Питомец не «погибает» и не получает травм (требование ТЗ Депфина).

## Интерфейс
*(Строго по вайрфреймам и экрану событий)*
- Всплывающее тревожное, но дружелюбное окно при открытии главного экрана.
- Карточка события: иконка (подорожник/бинтик), заголовок («Ой! Финни уколол лапку»), описание проблемы.
- Кнопка действия: «Вылечить за X монет» с индикацией списания.
