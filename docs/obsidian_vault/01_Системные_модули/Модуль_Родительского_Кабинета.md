# Модуль Родительского Кабинета

## Описание
Пространство отдельной авторизованной родительской сессии. Предоставляет объективную аналитику финансового поведения ребенка, выявляет паттерны ошибок без негативных оценок и позволяет назначать реальные домашние дела с вознаграждением.

## Механика / Бизнес-логика
*(Строго по коду `backend/src/modules/parentView/`, `backend/src/modules/parentTasks/`, `lib/parent/`)*
- **Барьер входа:**
  - Отдельный маршрут при старте (`AppAudience.parent`) создает или восстанавливает родительскую сессию.
  - Дополнительный локальный барьер для общего устройства (PIN/биометрия/математический пример) в текущем коде не реализован и остается продуктовым и security-решением.
- **Аналитика прогресса ребенка (`ChildOverview`):**
  - Стадия развития питомца (1–3), баланс кошелька и сумма в копилке.
  - Число пройденных обучающих квестов.
  - Метрика финансовой дисциплины: «Дней по плану: X из Y завершенных дней».
  - Прогресс по текущей финансовой цели (название артефакта, накоплено X из Y).
- **Секция «Нужен разговор» (`_attentionItems`):**
  - Автоматически диагностирует системные трудности:
    - Питомец голоден (не закрыты обязательные траты).
    - Систематический перерасход по категории «Хочу».
    - Отсутствие регулярных отчислений в накопления.
  - Дает родителю нейтральные педагогические подсказки для беседы.
- **Домашние поручения (`assignments` с `origin = 'PARENT'`):**
  - Родитель создает произвольные задания (например, «Убрать в комнате», «Полить цветы»); библиотека шаблонов пока не реализована.
  - Лимит награды задается серверным `ECONOMY_RULES.parentRewardLimit`: сейчас **от 1 до 10 монет**.
  - Флоу выполнения: ребенок выполняет задание в жизни и жмет «Выполнено» -> родитель в кабинете подтверждает -> монеты поступают в кошелек ребенка.

## Интерфейс
*(Строго по вайрфреймам и `ParentDashboardScreen`)*
- Спокойная нейтральная цветовая гамма (`#F1EEE8`).
- Шапка с кнопкой возврата и именем ребенка.
- Сетка из трех карточек ключевых метрик: «Заданий пройдено», «Дней по плану», «Нужен разговор».
- Список раскрывающихся карточек внимания с рекомендациями.
- Раздел домашних дел с кнопками «Добавить дело» и галочками подтверждения.
