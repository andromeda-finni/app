# Модуль Настроек

## Описание
Системный экран управления параметрами приложения, переключением сложности учебных заданий, звукового сопровождения, параметров доступности и связывания с родительским кабинетом.

## Механика / Бизнес-логика
*(Строго по коду `lib/settings/child_settings_screen.dart`)*
- **Уровни сложности (`ChildDifficulty`):**
  - Строго **2 градации** (для целевой аудитории 7–11 лет):
    1. `beginner` («Начинающий», 7–8 лет): Упрощенные расчеты, поддержка визуальными монетами и ячейками, меньше товаров в корзинах.
    2. `advanced` («Продвинутый», 9–11 лет): Большее количество товаров, многошаговые вычисления, скрытые условия, проверка нескольких строк чека.
- **Доступность и мультимедиа:**
  - Тумблеры звуковых эффектов (`sound`) и фоновой музыки (`music`).
  - Режим крупного текста (`largeText`) для удобства чтения младшими детьми.
- **Связывание с родителем:**
  - Отображение текущего статуса привязки.
  - Поле ввода кода приглашения от родителя.
- **Сброс профиля:**
  - Кнопка полного сброса локальных данных для повторного прохождения сценариев (требование демонстрационного режима ТЗ).

## Интерфейс
*(Строго по вайрфреймам)*
- Диалоговое или отдельное окно с хедером «Настройки» и кнопкой «Назад».
- Блоки: «Родитель», «Обучение» (выпадающий список сложности), «Звук и отображение».
