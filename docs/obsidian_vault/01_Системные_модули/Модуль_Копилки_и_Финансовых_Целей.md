# Модуль Копилки и Финансовых Целей

## Описание
Обеспечивает формирование навыка отложенного потребления и регулярных сбережений: постановка финансовой цели (выбор артефакта), пополнение копилки из бюджета или кошелька, возможность безопасного снятия и выкуп артефакта при достижении нужной суммы.

## Механика / Бизнес-логика
*(Строго по коду `backend/src/modules/goals/`, `lib/economy/savings_screen.dart`, `docs/economy-changes.md`)*
- **Выбор финансовой цели:**
  - Цель выбирается из каталога артефактов (`shop_items` с типом `ARTIFACT`, стоимость 80–150+ монет).
  - В первый день игры выбор цели обязателен до начала планирования бюджета.
  - **Правило фиксации цели:** Сервер запрещает отмену, замену или постановку на паузу активной цели до момента ее выкупа (предотвращение импульсивного распыления накоплений).
- **Пополнение копилки:**
  - Автоматически: при утверждении утреннего плана бюджета переводится сумма `savings_amount`.
  - Вручную: через экран Копилки кнопками фиксированного пополнения (+5, +10 монет). Ручное пополнение разрешено только сверх обязательного резерва (10 монет на еду). Пополнение сверх стоимости цели допускается.
- **Снятие средств из копилки:**
  - Разрешен возврат монет из копилки в кошелек.
  - Требует явного подтверждения через диалог, предупреждающий об увеличении срока достижения цели.
- **Достижение и получение цели (`claimGoal`):**
  - При `savings_balance >= target_amount` статус цели меняется на `ACHIEVED`.
  - При нажатии «Забрать артефакт» из копилки списывается точная стоимость предмета.
  - Артефакт заносится в таблицу `inventory_items` ребенка.
  - Игроку сразу открывается каталог для выбора следующей мечты (остаток накоплений сохраняется).

## Интерфейс
*(Строго по вайрфреймам и `SavingsScreen`)*
- **Карточка текущей мечты:**
  - Иллюстрация артефакта, крупное название и стоимость.
  - Горизонтальный прогресс-бар накоплений: «Накоплено X из Y монет».
  - Подпись: «Осталось накопить: Z монет».
- **Кнопки управления средствами:**
  - Крупная зеленая кнопка: «Пополнить копилку».
  - Вторичная текстовая/контурная кнопка: «Вернуть в кошелёк».
- **Кнопка триумфа:** При 100% заполнении появляется яркая акцентная кнопка «Получить артефакт!».
