# Модуль Авторизации и Онбординга

## Описание
Обеспечивает первичный вход пользователя, выбор роли («Ребёнок» или «Родитель»), автономную гостевую регистрацию без паролей и персональных данных, а также 4-шаговый сценарий знакомства с игровым миром и создание виртуального питомца.

## Механика / Бизнес-логика
*(Строго по коду `lib/main.dart`, `lib/onboarding/`, `backend/src/auth/routes.ts`)*
- **Выбор роли (`RoleChoiceScreen`):**
  - Пользователь выбирает вход как `AppAudience.child` или `AppAudience.parent`.
- **Детский профиль (гостевой режим):**
  - Не требует логина, email или пароля (соответствие ТЗ Депфина по защите детских данных).
  - При первом входе вызывается `POST /auth/child/register` (без авторизации).
  - Сервер генерирует сессионный JWT-токен роли `CHILD`, сохраняемый локально через `AuthStorage` (Secure Storage).
  - Начальный баланс кошельков при регистрации равен **0 монет** (стартовый бонус 50 монет удален в актуальной экономике).
- **Статус онбординга (`GET /onboarding/status`, `PUT /onboarding/progress`):**
  - Прогресс онбординга персистентен на сервере и состоит из 4 шагов:
    1. `step1`: Ввод имени питомца (валидация: не пустое, обрезка пробелов) и выбор окраса шерсти (`furOptionId`). Данные сохраняются через `PUT /pet`.
    2. `step2`: Сюжетное знакомство с персонажем Грошиком/Финни и сказочным лесом.
    3. `step3`: Обучение концепции бюджета: разделение на 3 корзины («Надо», «Хочу», «Цель»).
    4. `step4`: Финальная готовность к игре, переход к основному интерфейсу (`MainShell`).
- **Связывание с родителем:**
  - Опционально создается код приглашения (`POST /auth/invites`) для привязки к аккаунту родителя.

## Интерфейс
*(Строго по вайрфреймам `senior-ux-ui-wireflow-1-5` и коду)*
- **Экран выбора роли:** Две крупные дружелюбные карточки с иллюстрациями: «Я ребёнок» и «Я взрослый».
- **Экран создания питомца (Шаг 1):**
  - Верх/Центр: Крупный анимированный аватар питомца в корзинке/домике.
  - Поле ввода имени питомца с плейсхолдером.
  - Палитра выбора цвета шерсти (3 круглые кнопки с цветными образцами: базовый, полосатый, рыжий).
  - Кнопка продолжения «Дальше» (круглая с иконкой стрелки/галочки).
- **Информационные шаги онбординга (Шаги 2–4):**
  - Иллюстрация персонажа с диалоговым облачком («речевой пузырь»).
  - Наглядные визуальные метафоры: горшочек для монет, 3 миски для категорий бюджета.
  - Кнопка «Начать игру» на финальном шаге.
