# Модуль Экономики и Игровых Периодов

## Описание
Фундаментальный модуль распределения ресурсов, смены игровых дней (периодов), планирования личного бюджета («Надо», «Хочу», «Цель»), контроля обязательного продуктового резерва и подведения итогов исполнения бюджета (план/факт).

## Механика / Бизнес-логика
*(Строго по коду `backend/src/modules/economy/`, `backend/src/modules/periods/`, `docs/economy-changes.md`)*
- **Игровой день (период):**
  - Дискретный цикл финансовых решений без жесткой привязки к астрономическому времени.
  - Старт нового дня (`POST /periods`): игроку начисляется ежедневный доход **30 монет** (`ECONOMY_RULES.dailyIncome`).
  - В первый игровой день начисление 30 монет происходит строго после выбора первой мечты/цели в Копилке.
- **Обязательный продуктовый резерв:**
  - Базовый несгораемый резерв на питание составляет **10 монет** (`ECONOMY_RULES.foodReserve`).
  - Система жестко блокирует попытки потратить эти 10 монет на категорию «Хочу», перевести в Копилку или положить в Сундук Морозко.
- **План личного бюджета (`budget_plans`):**
  - Ребенок распределяет доступные 30 монет по 3 направлениям:
    - `need_amount` («Надо»): обязательные нужды (еда, уход), минимум 10 монет.
    - `want_amount` («Хочу»): развлечения, игрушки.
    - `savings_amount` («Цель»): перевод в накопления.
  - Валидация: `need_amount + want_amount + savings_amount == available_amount`.
  - При подтверждении плана (`POST /periods/:id/budget-plan/confirm`): сумма `savings_amount` немедленно списывается с основного кошелька и переводится на кошелек накоплений (`SAVINGS`).
- **Закрытие дня и сопоставление План/Факт (`calculateDayOutcome`):**
  - `needCovered`: `actualNeed >= requiredNeed` (питомец накормлен).
  - `planFollowed`: `needCovered && actualWant <= plannedWant && netSavings >= plannedSavings`.
  - Формирование 1–2 понятных рекомендаций для ребенка без демотивации и штрафов.

## Интерфейс
*(Строго по вайрфреймам и экрану `HomeScreen`)*
- **Свиток бюджета на главном экране:**
  - В начале дня интерактивные зоны игр заблокированы до утверждения бюджета.
  - По клику на свиток открывается диалог распределения 30 монет с ползунками или кнопками (+/-).
  - Кнопка «Утвердить план» становится активной только при распределении ровно 100% доступных средств.
- **Планка балансов в шапке:**
  - Иконка кошелька: доступные монеты для трат (`spendable`).
  - Иконка свинки/сундучка: сумма накоплений (`savings`).
