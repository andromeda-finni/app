# Экран Родительского Дашборда

## Описание
Аналитический интерфейс родителя для наблюдения за образовательным прогрессом ребенка и назначения семейных поручений.

## Механика / Бизнес-логика
*(Строго по коду `lib/parent/parent_dashboard_screen.dart`)*
- Отдельная авторизованная родительская сессия. Дополнительного PIN/биометрического барьера на общем устройстве пока нет.
- Полная прозрачность игрового прогресса (квесты, кошелек, копилка, цель).
- Назначение реальных домашних дел с вознаграждением 1–10 монет; верхняя граница приходит из серверного правила `parentRewardLimit`.

## Интерфейс
*(Строго по коду и вайрфреймам)*
- Хедер с кнопкой выхода в выбор роли.
- Крупная плашка: «Имя_Питомца: прогресс».
- 3 счетчика:
  - «Заданий пройдено» (число).
  - «Дней по плану» (X из Y).
  - «Нужен разговор» (количество активных тем для совместного обсуждения).
- Карточки подсказок для беседы (например, напоминание обсудить приоритеты трат).
- Список поручений с кнопками создания и подтверждения выполнения.
