# Экран Карта Заданий

## Описание
Вертикальная свиточная карта волшебной страны, по которой ребенок продвигается от Деревенского огорода у подножия к Сказочному парку на вершине, проходя обучающие квесты и зарабатывая монеты.

## Механика / Бизнес-логика
*(Строго по коду `lib/quest_map/quest_map_screen.dart`, `lib/quest_map/quest_map_data.dart`)*
- **Структура маршрута (8 узлов):**
  1. `repka`: «Репка» (y=2110)
  2. `mole`: «Крот с лупой» (y=1845) — запускает `MoleGameScreen` (`Q_MOLE_FINE_PRINT`)
  3. `ivan`: «Сборы в дорогу» (y=1575)
  4. `goldfish`: «Домик у моря» (y=1305)
  5. `fox`: «Хитрый Лис» (y=1040) — запускает `FoxEventDialog`
  6. `bakery`: «Пекарня» (y=780)
  7. `tugriki`: «Тугрики» (y=515) — запускает `TugrikiGameScreen` (`Q_TUGRIKI_CURRENCY`)
  8. `badger`: «Сказочный парк» (y=250)
- **Состояния узлов (`QuestMapNodeState`):**
  - `completed`: Квест пройден на сервере (золотая окантовка, галочка).
  - `current`: Текущий доступный квест (анимированная пульсирующая рамка, автоскролл к нему при входе).
  - `locked`: Будущий квест (затемнен, замочек).
- **Синхронизация прогресса:**
  - При входе на вкладку экран запрашивает `/economy/state` и список выполненных заданий.

## Интерфейс
*(Строго по вайрфреймам и коду)*
- Вертикальный свиток канваса высотой 2320 пикселей с извилистой тропинкой, соединяющей точки.
- Узлы представлены круглыми кнопками с тематическими эмодзи и персонажами.
- По тапу на узел выезжает нижняя шторка (`showModalBottomSheet`):
  - Крупная иконка, название квеста и локация.
  - Описание обучающей задачи.
  - Награда за прохождение (+10 / +12 / +15 монет).
  - Кнопка «Начать задание» (для готовых игр) или описание сценария.
