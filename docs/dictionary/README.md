# Обучающий словарик

Подключён к игре после просмотра отдельного Flutter-примера. Основа интеграции: `main @ 5a124fb`. Нижние вкладки, экономика, награды и прохождение квестов не меняются.

## Входы

- На доме прежняя кнопка 48×48 слева сверху стала меню с пунктами «Словарик» и «Настройки». Домашний тур и доступная подпись обновлены вместе с действием кнопки. Из «Копилки» настройки по-прежнему открываются напрямую.
- В бюджетной сцене «Тугриков» добавлено слово «бюджет». Двойное нажатие открывает определение, один пример и однократное сообщение после успешного сохранения. В объяснении есть переход к общему словарику. Остальные реплики пока не размечены.
- Определение и большой свиток открываются поверх игры. Закрытие и системное «Назад» не меняют шаг квеста, выбранные покупки или баланс.

## Свиток и оформление

Непрерывная лента бумаги с неровными боковыми краями уходит за верхнюю и нижнюю границы экрана. В ней ровно 50 различных терминов в алфавитном порядке. Поиск, фильтры «Все слова / Читали / Впереди» и тихий счётчик прочитанных объяснений закреплены сверху. Записи строятся лениво; по нажатию раскрывается одна. Незнакомые слова тоже разрешено читать сразу. Наград и постоянного значка книги на игровом экране нет.

Текст остаётся живым, масштабируется с настройкой шрифта и использует существующие PT Serif / Monomakh. Подсветка — золотое свечение букв обычного `TextSpan` без смены размера и начертания. Двойное нажатие, клавиатура Enter и доступное действие термина ведут к одному объяснению. Уменьшенное движение отключает пульсацию и анимации нового модуля. Общий `GameAudioService` играет пергамент только при открытии большого свитка и учитывает существующую настройку звука.

## Хранение и ограничения

Отметки чтения локальны устройству. `DeviceDictionaryStorage` сначала получает существующий `/pet`, затем использует стабильный ID питомца вместе с адресом backend для отдельного ключа в `FlutterSecureStorage`. Токен не используется как имя ключа; отсутствующий профиль не получает общий анонимный словарик. Один контроллер принадлежит `MainShell` и передаётся в «Тугрики». Перезапуск сохраняет отметки того же профиля, вход другого профиля их не наследует. При пересоздании питомца получается новый набор отметок.

Синхронизации между устройствами пока нет; новый backend-контракт, миграция БД и развёртывание сервера для этого изменения не требуются. Записи отдельной пробы не переносятся в детские профили. Ошибка загрузки или записи отметок не закрывает определения: их можно читать и повторить сохранение. Счётчик означает открытие объяснения, а не проверку усвоения.

Все 50 слов перечислены в [WORD_INVENTORY.md](WORD_INVENTORY.md), вместе с источниками из игры. Тексты объяснений находятся в `lib/dictionary/dictionary_catalog.dart`. Авторская разметка реплик сделана только для первого примера; остальные термины следует подключать отдельно, без массовой замены строк.

## Проверка

```sh
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --debug --no-pub
```

Специальные тесты покрывают 50 уникальных записей, поиск с «е/ё» и альтернативными названиями, фильтры, запись без потерь при параллельном чтении, повтор после ошибки, отсутствие ложного уведомления, изоляцию профилей/серверов, отсутствие анонимного хранилища, прокрутку до последнего термина и экран 320 px с текстом 200%. Интеграционные widget-тесты проходят через настоящее меню дома и настоящий сюжет «Тугриков» до бюджетной сцены.

Фактура и происхождение иллюстрации описаны в `assets/dictionary/ART.md`; звук и CC0-лицензия — в `assets/dictionary/AUDIO_SOURCES.md`.
