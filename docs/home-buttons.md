# Кнопки домика

По умолчанию панель домика использует бордовые восковые печати в стиле словарика.
Общий компонент `WaxSeal` находится в `lib/theme/wax_seal.dart`; экспорт из
`lib/dictionary/word_token.dart` сохранён для существующих импортов.

Прежние цветные кнопки, их цвета и индикатор внимания сохранены в
`HomeSidePanel`. Чтобы вернуть прежнее оформление всей панели, пересоберите:

```powershell
flutter run --dart-define=HOME_WAX_SEAL_BUTTONS=false
```

Для APK используйте тот же параметр с `flutter build apk`. Для возврата печатей
уберите параметр либо задайте `HOME_WAX_SEAL_BUTTONS=true`.
Режим также можно выбрать через `HomeSidePanel(style: HomePanelStyle.classic)`.

Оба оформления используют одни действия, блокировку занятых кнопок, подсказки
и подписи для экранного диктора. Оформления проверяются в
`test/home_side_panel_test.dart`.
