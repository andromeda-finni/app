# Фигурное зеркало с отражением

Локальная ветка: `codex/fairytale-mirror-reflection`, основана на
`origin/main` (`5a124fb`), синхронизирована с `0457a86` 17 октября 2026.

## Поведение

- Экран итогов дня использует фигурное зеркало с золотой рамой, гравировкой,
  голубым стеклом, бликами и отражением питомца над планом и фактом.
- `HomeScreen` передаёт питомца после обновления состояния в конце дня.
  Отражение использует `Pet.assetPath`, сохраняя окрас и настроение из домашнего
  экрана. Изображение отражено по горизонтали, слегка тонировано и растворяется
  в стекле у нижнего края.
- Без переданного питомца показывается базовый полосатый Грошик. Допущение:
  отражаем текущее состояние питомца; контракт итогов дня не хранит отдельный
  исторический портрет.
- При крупном тексте или недостатке ширины план и факт идут друг под другом.
  Экран прокручивается до совета и кнопки «Продолжить».
- Боковые отступы 36 px и нижний отступ 90 px сохраняют плашки в прямой части
  зеркала, выше фигурного сужения. Подписи внутри плашек выровнены по центру.
- Появление отражения учитывает системную настройку отключения анимаций.
- Рама и стекло нарисованы Flutter. Используются существующие изображения
  питомца; новые ассеты и зависимости не нужны.

## Локальный просмотр

Предпросмотр использует настоящий `DaySummaryScreen` и локальные примеры данных,
поэтому для просмотра не требуются авторизация, backend или БД. Рабочий вход
`lib/main.dart` использует серверные данные, как прежде.

```powershell
flutter pub get
flutter run -d chrome -t tool/preview_day_summary.dart
```

Либо собрать и открыть статический просмотр:

```powershell
flutter build web -t tool/preview_day_summary.dart --no-web-resources-cdn
node tool/serve_mirror_preview.cjs
```

Адрес: `http://127.0.0.1:8787`. Порт можно изменить через `PORT`.
Если платформа web ещё не настроена локально, сначала выполнить
`flutter create --platforms web .`; каталог `web/` уже исключён из Git в main.

Параметры URL: `fur=red|white|striped`, `success=true`, `largeText=true`.
Это параметры отдельной точки входа для просмотра, в основной экран они не
добавлены.
