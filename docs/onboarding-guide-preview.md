# Пробный онбординг

Отдельный Flutter-просмотр нового оформления. Обычная точка входа приложения
и действующий `OnboardingFlow` не изменены. Слияние этой ветки само по себе
не заменяет онбординг в игре.

## Запуск

После `flutter pub get`:

```sh
flutter run -d chrome -t lib/main_onboarding_preview.dart
```

Если в локальной копии отсутствует Web-платформа, сначала создайте её стандартной
командой `flutter create --platforms=web .` (проверьте получившиеся изменения).
На Android можно запускать тот же Dart entry point через `flutter run -d <device-id>`.
Нативная Android-сборка этого варианта пока не проверялась.

## Экраны

1. Имя, шёрстка и ошейник котёнка.
2. Знакомство с героем.
3. История о покупках без плана.
4. Демонстрация объяснения слова «бюджет» двойным нажатием или кнопкой.
5. Распределение десяти учебных монет через существующий `TutorialBudgetCard`.
6. «Твой день»: план, забота о питомце, задания и итоги.
7. Демонстрация карты и отметки новой просьбы.
8. Объяснение энергии и подсказок.

Для прямого просмотра страницы в Web используйте `?page=0` … `?page=7`.
На страницах, открытых напрямую, используется демонстрационный Грошик.

## Границы прототипа

- Нет сетевых запросов, регистрации, изменений кошелька или выдачи наград.
- Выбранное имя и внешность сохраняются только в памяти открытого просмотра.
  Обновление страницы сбрасывает данные.
- Назад сохраняет введённые данные и учебное распределение монет.
- Создание питомца и распределение всех десяти монет нельзя пропустить.
- Полный словарь не реализуется заново: здесь только демонстрация одного слова.
- Значок просьбы — предложение оформления, а не новая система ежедневных квестов.
- Кнопка «Начать приключение» показывает финал просмотра, не открывает игровой профиль.

## Подключение после согласования

Дополнительные страницы нужно встроить в существующий `OnboardingFlow`, сохранив
его серверные контрольные точки, восстановление прогресса и однократное создание
первого дня с десятью монетами. Не подключать отдельный просмотр вместо настоящего
онбординга: в нём намеренно нет сохранения профиля и серверных операций.

Проверки: `flutter analyze --no-pub`,
`flutter test --no-pub test/onboarding_guide_preview_test.dart`.
