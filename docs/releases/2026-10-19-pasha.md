## Подключение и возврат кнопок

Перед запуском обновлённого backend применить миграции стандартным скриптом `./db/scripts/migrate.sh` в настроенном окружении. Новая миграция Лиса — `db/migrations/0036_fox_daily_events.sql`; она добавляется к существующей `0036_catch_food_sessions.sql`, это разные файлы. Проверка `/health` обновлённого backend требует миграцию Лиса.

По умолчанию включены новые печати. Для возврата прежних цветных кнопок пересобрать приложение:

```powershell
flutter run --dart-define=HOME_WAX_SEAL_BUTTONS=false
```

Тот же параметр поддерживается командой `flutter build apk`. Удаление параметра возвращает новые кнопки. Подробности: [home-buttons.md](../home-buttons.md). Для полного отменяющего коммита оформления предусмотрен обычный `git revert de94ac7`.
